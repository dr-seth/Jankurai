# perfect-web-api-db

Reference platform scaffold for the Humanlint native stack.

This fixture proves the file layout for:

- Rust backend boundaries
- TypeScript/Vite frontend boundaries
- PostgreSQL migrations and constraints
- OpenAPI contract source
- UX proof and observability docs

The fixture is intentionally small and does not ship a running product. It is the documented reference surface for Phase 09 and the source of truth for future golden-repo expansion.
