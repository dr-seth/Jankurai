The audit JSON should include the rule ID whenever a finding maps cleanly to one of these rules. Rules outside the initial set may use category IDs until they stabilize.

\subsection{Vibe-Coding Source Coverage}

Jankurai 0.7.0 maps every parsed row from \texttt{tips/vibe\_coding/tip1.txt}
through \texttt{tip5.txt} into \texttt{agent/vibe-coverage.toml}. Coverage is
detector-backed only when a narrowed row has deterministic rule coverage plus
proof/report evidence; partial when Jankurai has a reviewed control family but
still needs issue-specific fixture, CI, or governance evidence. The full
row-level registry is supplemental source material in
\texttt{agent/vibe-coverage.toml}; the generated machine-readable outputs are
emitted under \texttt{target/jankurai/} by the documented coverage command.
