\section{Related Work}

AI coding benchmarks and agents measure task completion, environment use, and agent-computer interfaces. SWE-bench evaluates real GitHub issue resolution, SWE-agent studies agent-computer interface design, OpenHands provides an open software-agent platform, Aider demonstrates terminal pair programming, and SetupBench and ContextBench isolate setup and context-retrieval failures \cite{sweBench2024,sweAgentAci2024,openhands2024,aiderGithub2026,setupBench2025,contextBench2026}. These systems evaluate or implement coding agents. Jankurai standardizes the repository-local merge decision those agents must satisfy.

Supply-chain and provenance standards secure artifacts and dependencies. SLSA defines incrementally adoptable supply-chain levels and attestations; SPDX standardizes software bill-of-materials data; OSV provides vulnerability data and scanner tooling; OpenSSF Scorecard automates posture checks \cite{slsaSpec2026,spdxSpecifications2026,osvScanner2026,openssfScorecard2026}. Jankurai uses similar evidence mechanics, but its boundary is the pull-request merge event: changed paths, owners, proof receipts, missing evidence, and witness decisions.

API and schema standards define contract surfaces. OpenAPI, OpenAPI Generator, Protocol Buffers/Buf, and JSON Schema separate normative contract definitions from generated or validated artifacts \cite{openapiSpecification2026,openapiGeneratorUsage2026,protobufOverview2026,bufDocs2026,jsonSchemaSpec2026}. Jankurai treats those contracts as inputs to merge conformance rather than as the whole standard.

Conformance ecosystems show how standards become adoptable. W3C process documents define maturity and review states, and Kubernetes conformance uses repeatable tests and submitted evidence to preserve interoperability across implementations \cite{w3cProcess2026,kubernetesConformance2026}. Jankurai follows that pattern with levels, schemas, fixtures, and stable rule IDs.

Agent instruction surfaces are emerging as repository policy. \texttt{AGENTS.md}, Codex project guidance, Claude memory files, Cursor rules, and GitHub Copilot repository instructions all shape agent behavior \cite{agentsMdSpec2026,openaiCodexAgentsMd2026,claudeCodeMemoryDocs2026,cursorRulesDocs2026,githubCopilotInstructions2026}. Jankurai does not replace those files; it routes them through one conformance model so instructions, proof lanes, and merge evidence do not diverge.

UI, accessibility, observability, and proof-output ecosystems provide the receipts. Playwright, Storybook, axe/WCAG practice, visual regression systems, OpenTelemetry, JUnit, and SARIF make rendered behavior, accessibility, runtime evidence, and machine-readable findings reviewable \cite{playwrightBestPractices2026,playwrightVisualComparisons2026,storybookVisualTests2026,storybookAccessibility2026,wcagTargetSizeMinimum2026,openTelemetryDocs2025,sarifSpec2023}. Jankurai's distinction is to bind those outputs into a versioned merge witness instead of leaving them as disconnected CI logs.
