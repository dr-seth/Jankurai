## Phase name: **Phase 01: Standard Stabilization**

This is the right phase to finish because the moonshot demands explicit intent, bounded authority, routed ownership/proof, declared generated truth, durable machine-readable evidence, and expiring exceptions. Phase 01 is the foundation that makes those promises safe before later phases add rule-engine, proof-ledger, UX, security, contract DB, repair, migration, benchmark, and autonomous behavior. 

My read of the repo is: `01-standard-stabilization.md` is marked complete, but it also says it is a docs-only execution plan and lists concrete implementation gaps that still need runtime, schema, report, doctor, security-lane, docs, and evidence work.  The phase log currently contains only a creation/pending entry, not a full closeout receipt with passing evidence.  So the best Phase 01 closeout is not “add more roadmap text.” It is to harden the public contract and evidence surfaces so Phase 02 and Phase 03 cannot build on soft promises.

The highest-value gap is this: the standard requires every audit output to expose version and stack identity fields, proof routing, findings, caps, dimensions, and repair queue information, and the Rust model already emits those fields.   But `schemas/repo-score.schema.json` currently does not require the full Phase 01 public report contract, including `paper_edition`, `target_stack_id`, `target_stack`, `scope`, `caps_applied`, and `hard_rules`.  That is exactly the kind of silent contract drift Phase 01 is supposed to prevent.

The second major gap is security-lane reality. The current `jankurai security run` wraps `tools/security-lane.sh` as one command, so the evidence cannot tell whether `gitleaks` was missing, `cargo audit` failed, `npm audit` found issues, or the wrapper itself broke.  The shell script also hard-codes tool behavior, while `agent/security-policy.toml` already declares enabled, required, and advisory tools.   The patch below makes the Rust runner policy-aware while keeping the shell script as a compatible fallback.

The third gap is artifact schema coverage. `validation.rs` validates many emitted artifacts, but the Phase 01 router names the core agent artifacts too: owner map, test map, generated zones, proof lanes, audit policy, security policy, standard version, UX policy, boundaries, and release evidence.  The current `ArtifactSchema` enum does not cover several of those core control files.  The patch below adds those schemas and makes `doctor` validate them.

Below is a **single copy-paste implementation block**. It creates the missing schemas, updates validation, makes security evidence policy-aware, strengthens doctor, tightens the repo-score contract, adds compatibility tests, updates CI/Justfile routing, and appends a Phase 01 finish log only after validation passes.

#!/usr/bin/env bash
set -uo pipefail

strict="${JANKURAI_SECURITY_STRICT:-0}"
status=0

run_or_skip() {
  local requirement="$1"
  local tool="$2"
  shift 2

  if command -v "$tool" >/dev/null 2>&1; then
    echo "run: $*"
    "$@"
    local code=$?
    if [ "$code" -ne 0 ]; then
      echo "fail: $tool exited $code" >&2
      if [ "$requirement" = "required" ]; then
        status="$code"
      fi
    fi
    return 0
  fi

  echo "skip: $tool not installed; requirement=$requirement; advisory outside strict mode"
  if [ "$requirement" = "required" ] && [ "$strict" = "1" ]; then
    echo "missing required security tool: $tool" >&2
    status=127
  fi
}

run_or_skip required gitleaks gitleaks detect --source . --redact --no-banner
run_or_skip advisory cargo cargo audit
run_or_skip advisory npm npm audit --audit-level=high
run_or_skip advisory syft syft . -o spdx-json=target/jankurai/security/sbom.spdx.json
run_or_skip advisory zizmor zizmor .github/workflows

exit "$status"
EOF

fn collect_security_tools(policy: &SecurityPolicyFile) -> Vec<String> {
    let mut tools = BTreeSet::new();
    for tool in policy
        .enabled_tools
        .iter()
        .chain(policy.required_tools.iter())
        .chain(policy.advisory_tools.iter())
    {
        tools.insert(canonical_security_tool(tool));
    }
    if tools.is_empty() {
        return collect_security_tools(&default_security_policy());
    }
    tools.into_iter().collect()
}

fn canonical_security_tool(tool: &str) -> String {
    let lowered = tool.trim().to_ascii_lowercase().replace('_', "-");
    match lowered.as_str() {
        "cargo-audit" | "cargo audit" => "cargo audit".into(),
        "npm" | "npm-audit" | "npm audit" => "npm audit".into(),
        other => other.to_string(),
    }
}

fn contains_security_tool(tools: &[String], candidate: &str) -> bool {
    tools
        .iter()
        .any(|tool| canonical_security_tool(tool) == canonical_security_tool(candidate))
}

fn security_tool_available(tool: &str) -> bool {
    match canonical_security_tool(tool).as_str() {
        "cargo audit" => std::process::Command::new("cargo")
            .args(["audit", "--version"])
            .status()
            .map(|status| status.success())
            .unwrap_or(false),
        "npm audit" => std::process::Command::new("npm")
            .arg("--version")
            .status()
            .map(|status| status.success())
            .unwrap_or(false),
        other => {
            let binary = other.split_whitespace().next().unwrap_or(other);
            std::process::Command::new(binary)
                .arg("--version")
                .status()
                .map(|status| status.success())
                .unwrap_or(false)
        }
    }
}

        if !available {

                    "strict mode blocks this lane"
                } else {
                    "recorded as skipped evidence"
                }
            );
            log_text.push_str(&format!("[{}]\n{}\n\n", step.label, message));
            if blocking && envelope_exit_code == 0 {
                envelope_exit_code = 127;
            }
            commands.push(SecurityLaneStep {

                shell_command: step.shell_command,
                tool: Some(step.tool),
                status: "skipped".to_string(),

                advisory: !blocking,
                stderr_excerpt: Some(cap_excerpt(&message, 500)),
                finding_count: None,
                highest_severity: Some(if blocking { "high" } else { "low" }.to_string()),
                normalized_decision: Some(if blocking { "block" } else { "review" }.to_string()),
            });
            continue;
        }

        log_text.push_str(&format!("[{}]\n$ {}\n", step.label, step.shell_command));
        let output = Command::new("bash")
            .arg("-lc")
            .arg(&step.shell_command)
            .current_dir(&repo)
            .output()
            .with_context(|| format!("run `{}`", step.shell_command))?;

        let code = output.status.code().unwrap_or(-1);
        let stdout = String::from_utf8_lossy(&output.stdout);
        let stderr = String::from_utf8_lossy(&output.stderr);

        if !stdout.is_empty() {
            log_text.push_str("[stdout]\n");
            log_text.push_str(&stdout);
            if !output.stdout.ends_with(b"\n") {
                log_text.push('\n');
            }
        }
        if !stderr.is_empty() {
            log_text.push_str("[stderr]\n");
            log_text.push_str(&stderr);
            if !output.stderr.ends_with(b"\n") {
                log_text.push('\n');
            }
        }
        log_text.push_str(&format!("exit_code: {code}\n\n"));

        let passed = output.status.success();
        if !passed && step.required && envelope_exit_code == 0 {
            envelope_exit_code = if code == 0 { 1 } else { code };
        }

        commands.push(SecurityLaneStep {
            label: step.label,
            shell_command: step.shell_command,
            tool: Some(step.tool),
            status: if passed { "ran" } else { "failed" }.to_string(),
            exit_code: Some(code),
            advisory: !step.required,
            stderr_excerpt: if passed || stderr.is_empty() {
                None
            } else {
                Some(cap_excerpt(&stderr, 500))
            },
            finding_count: None,
            highest_severity: Some(
                if passed {
                    "ok"
                } else if step.required {
                    "high"
                } else {
                    "medium"
                }
                .to_string(),
            ),
            normalized_decision: Some(
                if passed {
                    "pass"
                } else if step.required {
                    "block"
                } else {
                    "review"
                }
                .to_string(),
            ),
        });
    }

    if commands.is_empty() {
        let message = "security policy did not define any enabled, required, or advisory tools";
        log_text.push_str(message);
        log_text.push('\n');
        envelope_exit_code = 1;
        commands.push(SecurityLaneStep {
            label: "security-policy".to_string(),
            shell_command: "agent/security-policy.toml".to_string(),
            tool: None,
            status: "failed".to_string(),
            exit_code: Some(1),
            advisory: false,
            stderr_excerpt: Some(message.to_string()),
            finding_count: None,
            highest_severity: Some("high".to_string()),
            normalized_decision: Some("block".to_string()),
        });
    }

    fs::write(&log_abs, log_text)?;

    let generated_at = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs()
        .to_string();

    let evidence = SecurityEvidence {
        schema_version: "1.0.0".to_string(),
        standard_version: STANDARD_VERSION.to_string(),
        generated_at,
        repo_root: repo.display().to_string(),
        git_head: git_head(&repo),
        lane: "security".to_string(),
        wrapper: SecurityWrapper {
            kind: "bash_script".to_string(),
            path: script_rel,
            strict,
        },
        exit_code: envelope_exit_code,
        elapsed_ms: started.elapsed().as_millis() as u64,
        log_path: log_rel,
        commands,
    };

    validation::write_json(&repo, ArtifactSchema::SecurityEvidence, &out, &evidence)?;

    if envelope_exit_code != 0 {
        anyhow::bail!("security lane exited with status {envelope_exit_code}");
    }

    Ok(())
}

fn policy_steps(policy: &SecurityPolicyFile) -> Vec<PolicySecurityStep> {
    let mut tools = BTreeSet::new();
    for tool in policy
        .enabled_tools
        .iter()
        .chain(policy.required_tools.iter())
        .chain(policy.advisory_tools.iter())
    {
        tools.insert(canonical_tool(tool));
    }
    if tools.is_empty() {
        return policy_steps(&default_security_policy());
    }

    tools
        .into_iter()
        .map(|tool| {
            let required = contains_tool(&policy.required_tools, &tool);
            PolicySecurityStep {
                label: tool.replace(' ', "-"),
                shell_command: command_for_tool(&tool),
                tool,
                required,
            }
        })
        .collect()
}

fn canonical_tool(tool: &str) -> String {
    let lowered = tool.trim().to_ascii_lowercase().replace('_', "-");
    match lowered.as_str() {
        "cargo-audit" | "cargo audit" => "cargo audit".to_string(),
        "npm" | "npm-audit" | "npm audit" => "npm audit".to_string(),
        other => other.to_string(),
    }
}

fn contains_tool(tools: &[String], candidate: &str) -> bool {
    tools
        .iter()
        .any(|tool| canonical_tool(tool) == canonical_tool(candidate))

### What this completes

This closes the Phase 01 workstream gaps directly:

**Artifact Contract Audit:** owner map, test map, generated zones, proof lanes, audit policy, security policy, standard version, boundaries, UX policy, proof/evidence outputs, and repo score now have schema coverage or existing validators.
