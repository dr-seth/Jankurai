# Executive Brief

## Title

**Minimum Semantic Surface: A Token-Aware Operating Standard for Agent-Efficient Rust Codebases**

## Core Thesis

The paper argues that agent-efficient Rust exports the smallest lawful repair program: clear owners, explicit contracts, legal edit zones, canonical proof lanes, typed diagnostics, raw-evidence paths, and security gates. The best token savings come from fewer wrong turns and narrower proof loops, not from shorter prompts alone.

## What Changed in V11

- Re-centered the manuscript on one thesis: MSS minimizes the lawful repair program at rest; runtime mediation addresses only the residual waste that survives in flight.
- Reordered the second half so proof lanes, security-gated validation, tooling, and ARI-v0 are fully established before any runtime discussion appears.
- Merged token doctrine, proof lanes, build acceleration, and security-gated validation into one operational section so the paper’s correctness story feels continuous instead of split across multiple late sections.
- Removed the doctrinal cumulative savings envelope and the per-agent WarpOS opportunity chart from the main paper.
- Replaced the old runtime-heavy visuals with a short carrier-centric runtime section that explains what MSS already removes and what a bounded mediation layer can still remove.
- Reframed WarpOS as bounded local corpus and mechanism evidence for residual runtime carriers, not as a co-equal paper contribution.
- Kept CrateAtlas as a localization and graph substrate only, not a separate category or flagship concept.
- Kept the future-work trio unchanged — `cargo-mss`, ProofLens, and `cargo-obligation-cache` — and explicitly tied each one back to the residual runtime layer as compile-time substrate.
- Moved the long runtime taxonomy, per-agent fingerprints, and implementation-heavy detail out of the main narrative and into the supplementary runtime companion note.

## Trust Boundary

The paper remains a trustworthy review and operating standard, not a local empirical report. It does not claim original empirical proof that minimum semantic surface improves agent outcomes. WarpOS appears only as bounded local corpus and mechanism evidence for residual runtime waste classes. The paper’s authority still comes from evidence synthesis, official Rust/Cargo mechanisms, production Rust maturity evidence, software-security guidance, and falsifiable future-work proposals.
